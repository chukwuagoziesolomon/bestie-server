## ⚠️ IMPORTANT: Free Tier Limitations

### Render Free Tier:
- **Web Service:** 750 hours/month (enough for 24/7)
- **PostgreSQL:** 100 MB storage, 90 days retention
- **Sleep after 15 min inactivity** (first request takes ~30 seconds)
- **Monthly bandwidth:** 100 GB
- **Automatic deploys:** Yes (on git push)

### Recommendations:
1. **Keep awake:** Use a ping service (e.g., UptimeRobot) to prevent sleep
2. **Monitor storage:** 100 MB fills up fast with media files
3. **Use Cloudinary:** For all image/video uploads (not local storage)
4. **Plan upgrade:** When you exceed 100 MB or need better performance

## 🐛 TROUBLESHOOTING

### Issue: Build fails
**Solution:**
```bash
# Check build logs in Render dashboard
# Common issues:
1. Missing dependencies in requirements.txt
2. Wrong Python version in runtime.txt
3. Build script not executable (chmod +x build.sh)
4. Environment variables not set
```

### Issue: Superuser not created
**Solution:**
```bash
# Check if environment variables are set:
DJANGO_SUPERUSER_EMAIL
DJANGO_SUPERUSER_PASSWORD
DJANGO_SUPERUSER_PHONE

# Run manually via Render Shell:
python create_superuser.py
```

### Issue: Database connection fails
**Solution:**
```bash
# Verify DATABASE_URL is set
# Check if PostgreSQL database is running
# Ensure database and web service are in same region
```

### Issue: WhatsApp notifications not working
**Solution:**
```bash
# Verify environment variables:
WHATSAPP_ACCESS_TOKEN
WHATSAPP_PHONE_NUMBER_ID

# Check Meta Developer Console for token validity
# Verify webhook URL is set in Meta dashboard
```

### Issue: Paystack webhook not receiving events
**Solution:**
```bash
# Configure webhook URL in Paystack dashboard:
https://bestyy-backend.onrender.com/api/webhooks/paystack/transfer/

# Enable events: transfer.success, transfer.failed, transfer.reversed
# Check webhook logs in Paystack dashboard
# Verify PAYSTACK_SECRET_KEY is set correctly
```

## 🚀 PRODUCTION OPTIMIZATION

### When to Upgrade from Free Tier:

1. **Traffic grows:** > 100 GB/month bandwidth
2. **Database full:** > 100 MB storage
3. **Performance issues:** Users experiencing slow responses
4. **Uptime critical:** Can't afford 15-minute sleep

### Recommended Upgrades:
- **Web Service:** Starter ($7/month) - No sleep, more resources
- **PostgreSQL:** Starter ($7/month) - 10 GB storage, backups
- **Redis:** Add for caching and Celery ($7/month)
